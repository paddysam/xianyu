# 闲鱼智能客服助手（浏览器插件）

在闲鱼**卖家工作台网页版**（seller.goofish.com）上运行的 Chrome 插件：

- 🤖 **自动回复**：监听买家新消息，知识库关键词直答 → 未命中调用 AI（OpenAI 兼容接口）生成回复
- 📦 **自动发货（接口驱动）**：直接读闲鱼订单接口，只对**「待发货」且未退款**的订单发货，按商品标题匹配规则发送卡密/链接，orderId 级别去重、每单只发一次。状态不看页面标签，避免发错货；无库存/找不到会话/状态不符一律跳过等人工
- 📚 **知识库**：关键词问答规则 + 自由文本店铺知识（喂给 AI 作为回答依据）
- 🛡️ **防呆**：只处理启用后的新消息（不翻旧账）、最新一条是买家消息才回、每会话每小时限频、回复前随机延迟模拟人工

> 参考了 [zhinianboke/xianyu-auto-reply](https://github.com/zhinianboke/xianyu-auto-reply) 的功能设计（关键词/商品/AI 多级回复 + 自动发货），
> 但实现方式不同：该项目是服务端程序（cookie + WebSocket 协议），本插件纯 DOM 操作跑在你已登录的网页里，不碰闲鱼加密接口。

## 安装

1. 打开 Chrome → 地址栏输入 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录下的 `extension` 文件夹

## 使用

1. 点插件图标 → ⚙️ 打开设置：
   - **AI 接口**：填接口地址（默认 `https://api.openai.com/v1`，可换中转/代理地址）、API Key、模型（如 `gpt-4o-mini`），点「测试接口连通性」确认可用
   - **知识库**：添加关键词直答规则；在「店铺知识」里写商品说明、价格、售后政策等
   - **商品发货**：添加规则，如商品标题匹配 `HeyGen`。发货方式二选一：
     - **固定内容**：每单发同样的文本（网盘链接、教程等）
     - **卡密库存**：把一批账号/兑换码一行一条存进去，每来一单自动发一条并扣库存；
       话术模板里用 `{卡密}` 占位（不写则卡密附在末尾）；库存 ≤2 条时日志告警，发完自动停发并提示补货
2. 打开闲鱼卖家工作台聊天页：<https://seller.goofish.com/#/im>
3. 点插件图标，打开总开关 → 页面右下角出现「🤖 自动客服运行中」
4. **保持该标签页开着**（可以放后台，但不能关）

## 自动回复优先级

```
买家新消息
  ├─ 命中知识库关键词 → 直接回复（不花 AI 费用）
  ├─ AI 开启 → 系统提示词 + 店铺知识 + 最近 8 条对话 → 生成回复
  └─ 都没有 → 兜底默认回复（可留空不回）
```

## 自动发货判定（接口驱动，防发错货）

发货是**独立流程**，与聊天回复分开，状态只认交易接口：

```
每轮轮询 mtop.taobao.idle.trade.merchant.sold.get（待发货订单）
  对每个订单逐层硬校验，任一不满足即跳过：
  ├─ orderStatus 必须 == 「待发货」        （权威状态，非页面标签）
  ├─ 未处于退款中（inRefund）
  ├─ orderId 未发过货（持久化去重，重载/重开不重发）
  ├─ 商品标题 + 规格 + 价格 精确匹配到规则  （同款不同价位分开，见下）
  ├─ 卡密库存有货                          （无货 → 记日志+桌面通知，等人工）
  └─ 按买家昵称能定位到会话               （找不到 → 记日志+桌面通知，等人工）
       ↓ 全部满足
  发送发货内容（带【自动发货】标记）→ 扣库存 → 记录 orderId 已发
```

任何一步不确定都**不发货、留给人工**，宁可漏发不错发。

### 按规格（SKU）发货，避免发错价位

同一个商品常有多个价位规格（如 HeyGen 会员号：新版¥169 / 旧版¥238 / 速刷号600积分¥128…）。
发货规则按**商品标题 + 规格 + 价格**三者精确匹配，每个规格配自己的卡密库存：

- 设置页点「🔄 从接口识别我的商品规格」→ 自动从你的订单里拉出所有「商品+规格+价格」，
  点「配置发货」一键建规则，规格文案与订单完全一致，**无需手输、不会输错**
- 规格 / 价格留空 = 不限（适合无规格的单一商品）
- 若某订单标题匹配到规则、但**没有对应规格/价格的规则** → 判定为"同款不同规格"，
  **绝不用别的规格卡密乱发**，直接转人工并桌面通知（这就是防止"128 的发成 238 的"的关键）

## 数据存储：浏览器本地 or MySQL 数据库

默认用浏览器本地存储（chrome.storage），开箱即用。

也可切换到 **本地 MySQL 数据库**（见 [server/](server/README.md)）：卡密库存、发货记录、知识库/商品规则都入库，
自动发货的"取卡+扣库存+去重"在数据库事务里完成，并发也不会发错/发重。启动后端后，在插件
「高级 → 数据源」填后端地址即可，本地已有规则会自动迁移进库。

## 目录结构

```
server/                     # 本地后端（MySQL，可选）：Express + mysql2，原子发货
extension/
├── manifest.json          # MV3 配置
├── background.js          # Service Worker：调 AI 接口、日志、统计
├── content/
│   ├── bridge.js          # 主世界桥：复用页面 mtop 库查订单（带签名/登录态），只读、脱敏回传
│   ├── selectors.js       # 页面 DOM 选择器（集中配置，改版时只改这里）
│   └── content.js         # 主逻辑：自动回复(DOM) + 自动发货(接口驱动)
├── options/               # 设置页（AI/知识库/发货规则/行为/高级）
├── popup/                 # 弹窗（开关、统计、日志）
└── icons/
```

## 页面改版怎么办

闲鱼前端用 CSS Modules，类名带哈希后缀（如 `conversation-item--JReyg97P`），插件用 `[class*="前缀--"]` 模糊匹配，小改版不受影响。若大改版失效：

1. F12 检查对应元素，找到新类名前缀
2. 设置页「高级 → 选择器覆盖」填 JSON 覆盖，无需改代码（键名见 `content/selectors.js`）

## 注意事项

- ⚠️ 自动化操作有账号风控风险，建议保持默认的随机延迟和限频设置，不要调得太激进
- ⚠️ 图片、语音、卡片消息暂不识别，只处理文本消息
- API Key 存在浏览器本地 `chrome.storage.local`，不会上传到任何服务器（只发给你配置的 AI 接口）
- 发货内容发出后无法撤回，配置卡密前先在自己的小号会话里测试一遍流程
