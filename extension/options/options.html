自动回复 · 知识库 · 自动发货

AI 接口配置

OpenAI 兼容接口，支持官方 API 或任意中转服务。 没有密钥？点这里注册获取地址和密钥 →

关键词直答

命中直接回复，不走 AI，省钱且快。关键词用逗号分隔，买家消息包含任意一个即命中，从上到下优先匹配。

店铺知识

自由文本，整体喂给 AI 作为回答依据。写商品详情、常见问题、发货说明、售后政策等。

自动发货规则

发货只对接口返回「待发货」的订单，按商品标题 + 规格 + 价格精确匹配（同款不同价位分开发货，避免发错）。每个订单只发一次。

库存总览

一眼看清每个商品/规格：放了哪些号、卖出多少、还剩多少。库存不足会标红，可直接补货。

回复行为

控制回复节奏，模拟人工操作，降低风控风险

发货设置

发货状态直接读取闲鱼订单接口（只对「待发货」且未退款的订单发货），不依赖页面标签，避免发错货。

数据源：本地后端（MySQL）

填了后端地址，则卡密库存、发货记录、知识库/商品规则都存到你的 MySQL 数据库（发货取卡走数据库事务，并发也不会发错/发重）。留空则用浏览器本地存储。

Telegram 推送（有单提醒到手机）

有人下单付款、需要人工处理、工作台掉线时，推送到你自己的 Telegram。 只会发给下面这个 Chat ID（即你自己），不会推给任何别人。

选择器覆盖

闲鱼页面改版导致插件失效时，在此用 JSON 覆盖默认选择器（键名见 content/selectors.js），留空使用默认。

数据导入 / 导出

备份或迁移全部配置（含 API Key、知识库、卡密库存）
